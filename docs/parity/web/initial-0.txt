Using keyboard shortcuts in the Arc Browser can significantly enhance your browsing efficiency and overall user experience. This guide provides a comprehensive list of Arc Browser's keyboard shortcuts, helping you navigate the browser more swiftly and effectively!
You can edit or remap keyboard shortcuts in Arc Settings.
Here a list of common shortcuts in Arc on macOS and Windows, and what they do.

Suggesting Shortcuts
: If there's a shortcut you think Arc could benefit from, don't hesitate to suggest it! Mac users can click Help > Contact the Team in the Mac menu bar, while Windows users can navigate to Arc menu > Help > Contact the Team.

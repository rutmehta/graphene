Automatic GitHub Live Folders streamline developers' workflows by automatically compiling your PRs in one place. When you next create a PR in GitHub, Arc will automatically create a Live Folder titled "Pull Requests," and populate it with your latest PRs.
How do Automatic GitHub Live Folders Work?
Automatic Activation
Engage with GitHub in Arc Browser, and witness the automatic creation of a "Pull Requests" Live Folder within your Sidebar. This folder instantly aggregates your active PRs, requiring no manual setup for activation.
Filtering Options
Right-click on the Live Folder to unveil a menu allowing you to filter your PRs. Choose to view PRs "Created by Me," "Drafts," or select specific repositories to be included in your folder.
Deactivation Process
Should you wish to remove the Live Folder from your Sidebar, a simple right-click on the folder provides an option to turn it off.
Retrieve Your Live Folder
If you've previously disabled the Live Folder and wish to reintegrate it into your workflow, right-click on the Sidebar, and select the option to re-enable the GitHub Live Folder.
A note on GitHub Enterprise Support
Automatic GitHub Live Folders relies on being able to pull information from github.com, so self-hosted or custom domain GitHub Enterprise instances will not work with the feature.

What are Previews?
Previews allow you to glance top sites without leaving your current tab. Just hover over a tab to see its Preview.
Which Sites Have Previews?
Gmail
/
Outlook Mail
: View recent emails, create a new email
Google Calendar
/
Outlook Calendar
: View upcoming meetings, join calls
Github
: View Open PRs and if they're approved
Notion
: View recent pages, create a new page
Confluence
: View recent pages
Figma
: View recent files, create a new file
Linear
: View issues, create a new issue
How to Turn On Previews
Previews work automatically when you hover on a Pinned or Favorited site!
Some previews, like Google Calendar, require you to sign in to the Preview before viewing content.
How to Turn Off Previews
You can toggle Previews on or off in Preferences. Visit Preview Preferences by going to
Arc > Settings
(in the Mac Menu Bar) and then selecting Previews in
General
. Uncheck previews you don't want to show on hover.
